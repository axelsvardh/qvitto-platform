# Qvitto platform

Monorepo for the Qvitto digital receipt platform.

| Folder | What |
|---|---|
| `apps/customer` | Customer app (Expo React Native), moved from `qvitto-frontend` |
| `apps/business` | Business app (new) |
| `services/api` | Express/Prisma/Postgres API, moved from `qvitto-backend` |
| `packages/shared` | Shared types (generated from the API contract) and design tokens |
| `specs` | Constitution, glossary and feature specs (spec-driven development) |

Install everything from the root with `npm install`.
